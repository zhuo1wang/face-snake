# 任务解锁皮肤 · 设计定稿

> 状态：**第一期已实现**（`js/tasks.js` + 任务页双轨进度条 + 六套奖励皮）  
> 用途：后续回顾任务条件、奖励皮与扩展约定。实现或改数值时请同步改本文。

---

## 1. 目标与原则

- 用可扩展的「任务表 + 结算检定 + 解锁仓库」支撑成长感。
- **进度跟模式挂钩，不跟地图挂钩**（空板 / 障碍图均算）。
- **现有 5 套默认皮肤 + 上传贴图：始终免费**，不作为任务锁。
- 奖励为 **6 套新皮肤**；方案 **A：一条任务解锁一张皮**。
- 完成即 **自动解锁**（不单独点领取）；结算可提示；皮肤列表未解锁显示锁 + 任务说明。

---

## 2. 系统骨架（便于扩展）

```
任务定义（配置）
  → 结算快照（本局事实）
  → 检定器（按条件类型）
  → 解锁仓库（unlocked skin ids 等）
```

- 加任务 / 改分数线：优先改配置，少改引擎。
- 加模式：快照增加字段 + 必要时新增条件类型。
- 加奖励种类：扩展 `rewardType`（当前先用 `skin`）。

### 2.1 结算快照（第一期字段）

| 字段 | 说明 |
|------|------|
| mode | `classic` / `timed` |
| mapId | 本局地图（第一期任务不筛地图，仍建议记录） |
| runScore | 本局得分 |
| endedByTime | 是否因时间到结束（限时） |
| bestScore | 该模式下用于任务的历史最高（经典档用） |

以后可加：难度、连击、食物数等。

### 2.2 条件类型（第一期）

| 类型 | 含义 |
|------|------|
| `best_score` | 历史最高分达标（可限 mode） |
| `run_score` | 本局得分达标（可限 mode） |

可叠加参数：`mode`、`minScore`、`requireTimeUp`（撑满 60 秒）等。  
地图第一期均为 **any**。

## 3. 六条任务

### 经典（历史最高 · `best_score`）

| 档 | 条件 | 奖励皮 |
|----|------|--------|
| 1 | 经典最高分 ≥ **15** | 竹青 |
| 2 | 经典最高分 ≥ **30** | 琥珀 |
| 3 | 经典最高分 ≥ **50** | 熔核 |

### 限时（本局为主 · `run_score`）

| 档 | 条件 | 奖励皮 |
|----|------|--------|
| 1 | 限时单局 ≥ **12** | 霜蓝 |
| 2 | **撑满 60 秒** 且得分 ≥ **15** | 电光 |
| 3 | 限时单局 ≥ **25** | 幽影 |

数值按默认「中」难度手感设定；可只改配置调参。

## 4. 奖励皮肤色系

主线：经典偏暖厚（生长 / 熔岩），限时偏冷闪（电光 / 虚空）；避开与免费皮（薄荷绿、赛博青、小猫杏、像素绿、甜心粉）撞脸。

| id（建议） | 名 | 色系感觉 | 对应任务 |
|------------|----|----------|----------|
| bamboo | 竹青 | 青灰绿，比经典薄荷绿更哑 | 经典 ≥15 |
| amber | 琥珀 | 橙金 → 深褐 | 经典 ≥30 |
| magma | 熔核 | 橙红芯 + 暗炭尾 | 经典 ≥50 |
| frost | 霜蓝 | 冰青白 → 钢蓝 | 限时 ≥12 |
| volt | 电光 | 亮黄白芯 → 电紫边 | 限时满60且≥15 |
| wraith | 幽影 | 近黑紫灰 + 淡边光 | 限时 ≥25 |

程序化头 / `body` / `bodyEnd` 实现时按上表配色；越靠后的档发光对比可更强。

## 5. 玩家体验要点

- 首页顶栏「任务」独立入口（与设置并列）。
- 任务页：**经典 / 限时各一条圆角进度条**，每条 3 个节点；节点主显分数，旁注皮名；限时中间档加「撑满」标记。
- 设置里皮肤列表：免费皮照常；任务皮未解锁不可选，展示解锁条件。
- 选用任务皮后，上传贴图仍可盖在头上（贴图能力不被奖励绑死）。
- 本机 `localStorage` 存完成与解锁；无痕 / 清数据会丢（见设置页隐私说明）。

## 6. 明确不做（第一期）

- 不按地图拆多套任务进度。
- 不回收或上锁现有免费皮肤。
- 不以限时理论天花（数百～八百）设任务档。
- 第一期不做每日任务、抽卡、账号云同步。
