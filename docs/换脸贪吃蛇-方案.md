# 自定义头像贪吃蛇 — 产品与技术方案

> 独立网页小游戏方案，**不依赖** get-hang / get-hang-web 业务项目。  
> 目标：电脑与手机浏览器均可玩；蛇头、食物均可上传照片自定义。

---

## 1. 产品定位

| 项 | 说明 |
|----|------|
| 建议名称 | 换脸贪吃蛇 / Face Snake |
| 形态 | **纯网页小游戏**（静态站点） |
| 运行端 | 电脑浏览器 + 手机浏览器（同一套代码） |
| 核心卖点 | 蛇头、食物都可换成用户上传的照片 |
| 明确不做 | 不装 App、不做 exe、不接后端、不对战排行榜 |

---

## 2. 功能清单

### 2.1 必做（MVP）— 已实现

1. **经典贪吃蛇**：移动、吃食物变长、撞墙/撞身结束、得分  
2. **自定义蛇头**：上传图片 → 自动居中裁成圆形 → 作为蛇头绘制  
3. **自定义食物**：同上流程，另一张图贴在食物格子上  
4. **双端操作**  
   - 电脑：方向键 / WASD  
   - 手机：滑动换向 + 底部虚拟方向键  
5. **基础 UI**：开始 / 暂停 / 再来一局、当前分、历史最高分  
6. **本地持久化**：蛇头图、食物图、最高分存入 `localStorage`  
7. **响应式布局**：竖屏手机、桌面均可完整操作  

### 2.2 可选（二期）

- 拖动 / 缩放裁剪框  
- 多套默认皮肤  
- 难度档位  
- PWA  
- 音效  
- 分享成绩图  

---

## 3. 技术选型

| 层 | 选择 |
|----|------|
| 渲染 | HTML5 Canvas |
| 逻辑 | 原生 ES Module JavaScript |
| 样式 | 纯 CSS |
| 存储 | `localStorage` + DataURL |
| 部署 | 任意静态托管 |
